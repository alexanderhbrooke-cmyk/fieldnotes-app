Fieldnotes privacy policy

Last updated 11 October 2026.

Fieldnotes is a private tool used only by its owner. It is not available to anyone else.

What Google data it uses

With the owner's consent, Fieldnotes uses the Google Calendar scope that lets an app create its own secondary calendar and manage events in that calendar only. It adds posting reminders and planned events to the "Fieldnotes" calendar. It cannot see, read or change any other calendar or any other Google data.

Where data is kept

Fieldnotes runs on the owner's own computer. The Google authorisation is stored there in encrypted form. No data is sent to any other server, sold, shared, used for advertising or used to train models.

Google API Services User Data Policy

Fieldnotes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the "Fieldnotes" calendar removes everything the app created.

Contact

Questions can be raised through this site's GitHub issues.
